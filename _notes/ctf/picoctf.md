## 参考資料

[picoCTF / CyLab Security Academy](https://picoctf.org/)

picoCTFの入口として共有されたURLです。2026年9月18日の確認時点では、Carnegie Mellon Universityの学習基盤「CyLab Security Academy」への移行案内が掲載されています。

学習を始める際は、リンク先にある[CyLab Security Academy](https://cylabacademy.org/)への案内を確認してください。
